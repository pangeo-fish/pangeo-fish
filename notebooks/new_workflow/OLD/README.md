# Previous light notebook

`pangeo_fish_with_light.ipynb` is the notebook of pull request 267. It computes the light likelihood on a 0.5 degree latitude/longitude grid, smooths it with `scipy.ndimage.gaussian_filter`, regrids it to HEALPix with xhealpixify and puts the nights on the days of the emission by the UTC date of the rising. It also has a lunar chapter.

It is kept for comparison. Use `../pangeo_fish_with_light.ipynb`.
